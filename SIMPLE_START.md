# 🚀 OCR Data Software Package - Simple 3-Step Start

## Quick Start (3 steps)

### 1. Start Server
```bash
cd "c:\Users\ANNAMAYA\Desktop\Computer Science\7th semester\Inscription Project\OCR_Data_Software_Package"
python -m http.server 8000
```

**Expected Output:**
```
Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...
```

✅ **Status:** Server is running!

---

### 2. Open Browser
```
http://localhost:8000
```

- Navigation tabs: Overview | Search | Formats | Documentation

✅ **Status:** Dashboard is loading!

## To Stop the Server

In the terminal where the server is running:
```bash
Ctrl+C
```

Then:
```
KeyboardInterrupt
```

**Done!** Server is stopped.
