# 🏛️ Ancient Inscription and Ancient Script Recognition using OCR

## 📌 Project Overview
Historical inscriptions, stone edicts, and ancient manuscripts hold the key to understanding civilizational shifts, culture, and lost heritages. However, manually deciphering these weathered, damaged, or non-standard ancient scripts is a monumental challenge for historians and linguists. 

This project bridges the gap between **Archaeology and Artificial Intelligence** by leveraging modern **Optical Character Recognition (OCR)** techniques to automate the recognition, digitization, and analysis of ancient scripts. By processing complex textures, uneven surfaces, and faded characters, this system aims to preserve linguistic heritage and accelerate digital epigraphy research.

---

## ✨ Features
* **ML Model Dashboard:** A dedicated interactive interface (`demo.html`) to test live inference, visualize model performance, and evaluate accuracy.
* **Unified Launcher:** A hassle-free, single-point execution script (`launcher.py`) that manages server setup and opens modules automatically.
* **Robust Preprocessing:** Handles noise, uneven lighting, and weathered textures typical of physical stone/metal inscriptions.
* **Digital Preservation:** Converts physical history into machine-readable digital data for further linguistic analysis.
